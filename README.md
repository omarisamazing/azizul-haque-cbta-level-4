# CBT&A Level-4 Caregiving Exam Prep Landing Page

This is a modern, high-performance, and responsive landing page for the **CBT&A Level-4 Caregiving Exam Preparation Guidebook** written by **S. M. Azizul Haque** (Senior Staff Nurse, NSDA Certified Trainer & Assessor).

The website serves as a landing page for students, caregivers, and trainers looking to learn more about the guidebook, review sample questions, and place orders directly.

---

## 🚀 Key Features

- **Bi-directional Light/Dark Mode:** Features a dynamic theme switcher with theme settings securely saved in the user's browser via `localStorage`.
- **Responsive & Mobile-First Design:** Engineered with adaptive grid and flexbox systems, rendering cleanly across desktops, tablets, and mobile screens.
- **3D Physics Book Cover Animation:** Simulates a realistic 3D physical book tilt, lift, and shadow effect upon hovering over the book cover.
- **Smooth Navigation & Scroll Animations:** Implements an native `IntersectionObserver` fade-in scroll animation for website sections and smooth-scrolling anchor links.
- **Accessible Native Accordions:** Uses semantic HTML `<details>` and `<summary>` elements to create accessible accordion lists for sample questions.
- **Interactive Ordering Modal:** Intercepts standard form submissions to display a styled modal popup confirming the user's order details.
- **Keyboard Navigation & Esc-Key Dismissal:** Supports keyboard standards by allowing users to dismiss active modals or the mobile navigation drawer with the `Escape` key.
